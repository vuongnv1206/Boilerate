# Backend workflow

Read [../../../AGENTS.md](../../../AGENTS.md), [../../../../AGENTS.md](../../../../AGENTS.md), [../../../../agents/backend.md](../../../../agents/backend.md) and [../../../../docs/README.md](../../../../docs/README.md) before editing. Check the owning module documentation and [../../../../docs/overview/roadmap.md](../../../../docs/overview/roadmap.md). API, database and local operation contracts live in [../../../../docs/contracts/commerce-api.md](../../../../docs/contracts/commerce-api.md), [../../../../docs/contracts/commerce-database.md](../../../../docs/contracts/commerce-database.md) and [../../../../docs/contracts/local-runbook.md](../../../../docs/contracts/local-runbook.md).

Keep API, domain, application and persistence changes in their owning module layers under `src/`. Business features follow the modular Vertical-Slice convention: each action lives in `src/Application/<Module>/<Submodule>/<UseCase>Request.cs` containing the MediatR `IRequest<T>`, `CustomValidator<T>`, and `IRequestHandler<T, R>` in one file (using `IApplicationDbContext` and `ICommerceUnitOfWork`), while thin controllers under `src/Host/Controllers/<Module>/` dispatch via `Mediator.Send(...)` — never introduce God-services in `src/Infrastructure/`. For material business, API or database changes, draft or update the feature plan using [../../../../docs/templates/feature-plan.md](../../../../docs/templates/feature-plan.md) and update the owning module docs in `../../../../docs/` directly. Document ownership, cardinality, constraints, concurrency, deletion and migration strategy when schema changes. Preserve authorization (at both controller and handler), transaction and idempotency behavior established by the affected source.

Local development runs on SQL Server (`mssql`) by default without Docker; preserve switchable `DBProvider` (`mssql` | `postgresql`) and scaffold migrations for both `Migrators.MSSQL` and `Migrators.PostgreSQL` whenever the EF model changes. Run local checks appropriate to changed behavior; do not imply an unconfigured provider or deployment was tested. Keep raw logs in ignored `artifacts/` and clean up any temporary files before finishing.
