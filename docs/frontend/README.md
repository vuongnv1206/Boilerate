# Frontend — điểm điều hướng

FE hiện nằm trong thư mục sibling [Frontend](../../../Frontend/README.md) của workspace, repository độc lập `Boilerate.Frontend`. Source có Collections, Orders/Shipping/After-sales, Renewals, quản trị hệ thống và browser session. Source và CI FE độc lập với repo này.

- [Bản đồ source](../../../Frontend/docs/architecture.md).
- [Collections](../../../Frontend/docs/features/live-admin-collections.md) và [giữ phiên](../../../Frontend/docs/features/persistent-session.md).
- [Lịch sử tính năng và bằng chứng FE](../../../Frontend/docs/README.md).

Các hồ sơ `features/history/verification` cũ trong thư mục này phản ánh mốc nền UI trước khi repo FE độc lập, không mô tả source hiện tại. Đọc docs trong repo FE cho công việc tiếp theo; không tạo bản sao tại đây. Kết quả mock/BE tests không thay bằng chứng FE thật.
